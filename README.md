# GapLens — AI-Powered Communication Gap Detector

> **“See what the conversation missed.”**  
> *AI-powered detection of unanswered questions, missed responses, repeated clarification, and unresolved discussions.*

---

## ⚡ Overview

**GapLens** is an AI-powered communication analysis platform engineered to audit multi-person transcripts (Slack, Teams, Discord, Zoom/Meet chats) and highlight communication failures with **verifiable, quoted conversational evidence**.

Built on a **Cyberpunk / Glitch Design System** featuring chamfered geometric panels, neon glowing states, CRT scanline HUD shaders, and terminal telemetry typography.

---

## 🚀 Key Features

1. **6 Core Diagnostic Rules**:
   - 🔴 **Unanswered Question**: Highlights explicit inquiries left stranded without replies.
   - 🟠 **Repeated Clarification**: Detects re-asking patterns caused by evasive or vague answers.
   - 🟡 **Unresolved Topic**: Catches debates, constraints, and conflicting proposals dropped without consensus.
   - 🔵 **Partial Answer**: Flags compound inquiries (e.g. "What time and where?") where only one clause was addressed.
   - 🟢 **Pending Follow-up**: Tracks verbal commitments ("I'll review the PR in an hour") that remain stalled.
   - 🟣 **Missed Response**: Identifies interleaved threads where one turn inadvertently strands another.

2. **Verifiable Conversational Evidence**:
   - Every detected gap provides direct, quoted conversational evidence with timestamps and speaker attribution.
   - Explanations generated by AI explain **Where** it occurred, **What** happened, **Why** it was detected, and **Which** messages provide the evidence.

3. **Communication Health Index**:
   - Structural resolution gauge (0–100%) measuring conversational follow-through and thread closure.

4. **Topic Intelligence & Structural Timeline**:
   - Clustering of discussion topics with resolution percentages and participant breakdowns.
   - Interactive chronological timeline showing questions, answers, and visual breakdown markers.

5. **Choose your analysis engine**:
   - Select OpenRouter API to analyze with the server-configured model. Analysis fails clearly if the server key or provider is unavailable.
   - Select Local AI to run the built-in heuristic analysis entirely in the browser without an API key.
   - API credentials remain in the server's ignored `.env` file and are never sent from the browser.
   - Pre-loaded with three realistic scenarios:
     - **Demo 1 — Project Planning Meeting** (Repeated meeting time queries, tech debate)
     - **Demo 2 — Software Team Incident** (Stalled code reviews, memory leak alerts)
     - **Demo 3 — Global Event Planning** (Keynote date conflict, venue hold expiration)

6. **Full-Featured Suite**:
   - Drag-and-drop file upload (.txt, .csv, .json).
   - Real-time search and multi-criteria filtering (by speaker, topic, gap type).
   - Interactive Gap Inspection Drawer with "Mark as Resolved" (confetti celebration) and "Dismiss".
   - Export analysis to JSON, CSV, or formatted print-ready PDF reports.

## 📦 Getting Started

### 1. Install Dependencies
```bash
# In root directory
npm install
npm install --prefix client
npm install --prefix server
```

### 2. Configure Environment (Optional)
To use OpenRouter, copy the root `.env.example` file to `server/.env`, set `OPENROUTER_API_KEY` to your key, and optionally choose a model with `OPENROUTER_MODEL` (default: `openai/gpt-4o-mini`). Restart the server after changing environment values. Then select **OpenRouter API** in Analyze or Settings. Alternatively, select **Local AI**; this mode does not need a key or server connection. You must select one of these modes before analyzing a conversation.

Never commit `server/.env` or share API keys in chat or screenshots. If a key has been exposed, revoke it and create a replacement. Use the **Settings** page to view the active provider and model and to adjust analysis preferences. The sun/moon control in the top bar switches between light and dark themes; the selected theme is saved in the browser.

### 3. Launch Development Environment
```bash
# Run both Backend API and Frontend Client concurrently:
npm run dev
```
- **Frontend App**: [http://localhost:5173/](http://localhost:5173/)
- **Backend API**: [http://localhost:5000/](http://localhost:5000/)

## 📡 REST API Reference

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/health` | Health status and active AI model telemetry |
| `POST` | `/api/analyze` | Parse and audit conversation transcript |
| `GET` | `/api/conversations` | Retrieve all archived audit sessions |
| `GET` | `/api/conversations/:id` | Fetch specific conversation session |
| `POST` | `/api/conversations/:id/resolve-gap` | Mark gap as resolved |
| `POST` | `/api/conversations/:id/dismiss-gap` | Dismiss gap flag |
| `DELETE` | `/api/conversations/:id` | Remove audit session from archive |
